class KXSwipe2DeleteBehavior¶

A mix-in class that adds swipe-to-delete functionality to a layout’s children.

(Some docstrings in this class are written in Japanese because the corresponding English documentation is already available in enable_swipe2delete_for_children().)

on_delete_requested(touch, child)¶
Parameters:

  • touch – The MotionEvent that triggered the on_delete_requested event, in window coordinates.

  • child – The child widget for which deletion was requested.

s2d_delete_distance¶

指が離れた際に on_delete_requested イベントを引き起こすのに必要なスワイプの移動量

s2d_direction = 'horizontal'¶

スワイプの方向

s2d_disabled = False¶

If either disabled or s2d_disabled is True, the swipe-to-delete functionality is disabled.

s2d_swipe_distance¶

タッチがスワイプとして認識されるために必要な移動量

s2d_touch_filter(t)¶

on_touch_down イベントがこの選別をくぐり抜けたタッチのみがスワイプとして認識され得る。 既定値は is_colliding_and_not_wheel()。

s2d_track_multiple_touches = False¶

偽(既定値)の場合、１つタッチを監視している間に始まった他のタッチは無視される。

disable_and_remove(touch, widget)¶

Default action performed when a swipe-to-delete gesture requests deletion.

def disable_and_remove(touch, widget):
    widget.disabled = True
    widget.parent.remove_widget(widget)

async enable_swipe2delete_for_children(layout, /, *, touch_filter=<function is_colliding_and_not_wheel>, direction='horizontal', swipe_distance=kivy.metrics.dp, delete_distance=kivy.metrics.dp, on_delete_requested=<function disable_and_remove>, track_multiple_touches=False)¶

Enables swipe-to-delete functionality for a layout’s children until the returned coroutine is cancelled.

Parameters:

  • touch_filter (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent], bool]) – Any touch whose on_touch_down event does not pass this filter is ignored. Defaults to is_colliding_and_not_wheel().

  • direction (Literal['horizontal', 'vertical']) – The swipe direction to detect.

  • swipe_distance – The minimum distance a touch must travel to be recognized as a swipe gesture.

  • delete_distance – The minimum distance a recognized swipe gesture must travel to trigger on_delete_requested when the touch is released.

  • on_delete_requested (Callable[[kivy.input.motionevent.MotionEvent, kivy.uix.widget.Widget], None]) – A callable invoked when a delete request is triggered. Defaults to disable_and_remove(). For its parameters, see KXSwipe2DeleteBehavior.on_delete_requested().

  • track_multiple_touches – Whether to track multiple touches simultaneously (multi-touch). If False (the default), once a touch starts being tracked, subsequent touches are ignored until the tracked touch ends or exclusive access to it is claimed by someone else.

ongoing_swipe2deletes()¶

Returns a list of (widget, touch) pairs for all ongoing swipe-to-delete gestures, where the widget is the widget being swiped and the touch is the MotionEvent associated with the swipe.

Return type:

list[tuple[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent]]
