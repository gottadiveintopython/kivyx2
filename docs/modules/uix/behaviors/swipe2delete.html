disable_and_remove(target, touch)¶

Default action performed when a swipe-to-delete gesture requests deletion.

def disable_and_remove(target, touch):
    target.disabled = True
    target.parent.remove_widget(target)

async enable_swipe2delete_for_children(layout, /, *, touch_filter=<function is_colliding_and_not_wheel>, direction='horizontal', swipe_distance=kivy.metrics.dp, delete_distance=kivy.metrics.dp, on_delete_requested=<function disable_and_remove>, track_multiple_touches=False)¶

Enables swipe-to-delete functionality for a layout’s children until the returned coroutine is cancelled.

Parameters:

  • touch_filter (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent], bool]) – Any touch whose on_touch_down event does not pass this filter is ignored. Defaults to is_colliding_and_not_wheel().

  • direction (Literal['horizontal', 'vertical']) – The swipe direction to detect.

  • swipe_distance – The minimum distance a touch must travel to be recognized as a swipe gesture. Defaults to dp(20).

  • delete_distance – The minimum distance a recognized swipe gesture must travel to trigger on_delete_requested when the touch is released. Defaults to dp(300).

  • on_delete_requested (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent], None]) – A callable invoked when a delete request is triggered. Defaults to disable_and_remove().

  • track_multiple_touches – Whether to track multiple touches simultaneously (multi-touch). If False (the default), once a touch starts being tracked, subsequent touches are ignored until the tracked touch ends or exclusive access to it is claimed by someone else.

get_active_swipe2deletes()¶

Returns a list of (widget, touch) pairs for all ongoing swipe-to-delete gestures, where the widget is the widget being swiped and the touch is the MotionEvent associated with the swipe.

Return type:

list[tuple[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent]]
