Drag & Drop¶

drop_tags & drag_tags¶

These two parameters work together as a filter.

For a dragged widget to be accepted by a drop target, their tags must have at least one element in common. For example:

import asynckivy as ak
import kivyx.uix.behaviors.drag_n_drop as dnd

ak.managed_start(dnd.enable_drag(widget1, drag_tags={"A", "B"}))
ak.managed_start(dnd.enable_drop_target(widget2, drop_tags={"B", "C"}))

In this example, widget1 can be dropped onto widget2 because they share the tag "B".

  • A tag doesn’t have to be a string; it can be any hashable object.

  • “drop_tags” must be a Set, whereas “drag_tags” can be any Collection (drop_tags.isdisjoint(drag_tags) must be a valid expression).

async enable_drag_for_children(layout, *, drag_tags=frozenset({None}), touch_filter=<function is_colliding_and_not_wheel>, consume_touch=False, triggers=(<function long_press>, ), track_multiple_touches=False, on_start=<function noop>, on_end=<function noop>)¶

Makes layout’s children draggable until the returned coroutine is cancelled.

Parameters:

  • touch_filter (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent], bool]) – Any touch whose on_touch_down event does not pass this filter is ignored. Defaults to is_colliding_and_not_wheel().

  • consume_touch (bool) – Whether to consume on_touch_down events that pass touch_filter.

  • triggers (Sequence[Callable[[kivy.input.motionevent.MotionEvent], Awaitable]]) – Drag starts when any of these gestures is detected.

  • track_multiple_touches (bool) – Whether to track multiple touches simultaneously (multi-touch). If False (the default), once a touch starts being tracked, subsequent touches are ignored until the tracked touch ends or exclusive access to it is claimed by someone else.

  • on_start (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent, Collection], Any]) – Called each time a drag starts. See on_start() for the callback parameters.

  • on_end (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent, Collection, Literal['succeeded', 'failed', 'cancelled']], ~typing.Any]) – Called each time a drag ends. See on_end() for the callback parameters.

  • drag_tags (Collection)

async enable_drop_target(widget, *, drop_tags=frozenset({None}), on_enter=<function noop>, on_leave=<function noop>, on_drop=<function _add_widget_and_return_true>)¶

Enables widget to act as a drop target until the returned coroutine is cancelled.

Parameters:

  • drop_tags (Set) – Drag classes accepted by this drop target.

  • on_enter – Called each time a dragged widget enters the drop target. See on_enter() for its parameters.

  • on_leave –

    Called each time a dragged widget leaves the drop target. See on_leave() for its parameters.

    For every on_enter call, a corresponding on_leave call is guaranteed, even if the drag is cancelled.

  • on_drop – Called each time a dragged widget is dropped on the drop target. See on_drop() for its parameters.

async enable_drop_target_with_insertion_indicator(layout, *, drop_tags=frozenset({None}), spacer_widgets=1)¶

Enables layout to act as a drop target with an insertion indicator until the returned coroutine is cancelled.

While a widget is dragged over the layout, a spacer widget is temporarily inserted to indicate where the widget would be inserted if it were dropped at that moment.

Parameters:

  • spacer_widgets (list[kivy.uix.widget.Widget] | int) – Widgets used as spacers during dragging. The number of spacer widgets determines the maximum number of simultaneous drags that can be handled. If an integer is provided, that many spacer widgets are created internally.

  • drop_tags (Set)

on_drop(drop_target, touch, drag_tags, dragged_widget)¶
Returns:

Return True to indicate that the drop was accepted. If False, the caller will continue searching for other drop targets.

Parameters:

  • drop_target – The widget that the dragged_widget was dropped onto.

  • touch – The MotionEvent that was used to perform the drag. It is represented in window coordinates.

  • dragged_widget – The widget that was dropped.

Return type:
