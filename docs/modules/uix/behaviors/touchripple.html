Touch Ripple¶

class KXTouchRippleBehavior¶

A mixin class that adds touch ripple effect to widgets.

(Some docstrings in this class are written in Japanese because the corresponding English documentation is already available in enable_touch_ripple_effect().)

ripple_allow_multiple = True¶

複数のタッチによって複数の波紋を発生させるか否か

ripple_clip_to_bounds = True¶

波紋の描画をwidget内に収めるか否か。widgetが既にそのような事を自身で行っている場合は偽にした方が効率面で吉。

ripple_color = '#FFFFFF44'¶

波紋の色

ripple_disabled = False¶

If either disabled or ripple_disabled is True, ripple effect is disabled.

ripple_fadeout_curve = 'linear'¶

波紋の薄まり方の緩急

ripple_fadeout_duration = 0.2¶

波紋が薄まるのにかかる時間

ripple_fadeout_on_exclusive_access = True¶

誰かがタッチへの排他アクセスを得た時に波紋が薄まり始めるか否か。 偽の場合は指が離れない限り波紋は薄まり始めない。

ripple_final_size = None¶

波紋が広がりきった時の直径。None(既定値)の場合は丁度widgetを覆う大きさ。

ripple_growth_curve = 'linear'¶

波紋の広がり方の緩急

ripple_growth_duration = 0.3¶

波紋が広がるのにかかる時間

ripple_initial_size¶

波紋発生時の直径

ripple_relative_coordinates = False¶

相対座標系(例：RelativeLayout, Scatter) のwidgetと合成する場合は真にしてください。

ripple_touch_filter(t)¶

on_touch_down イベントがこの選別をくぐり抜けると波紋が発生する。 既定値は is_colliding_and_not_wheel()。

async enable_touch_ripple_effect(widget, *, relative_coordinates=False, clip_to_bounds=True, touch_filter=<function is_colliding_and_not_wheel>, allow_multiple=True, initial_size=kivy.metrics.dp, final_size=None, growth_duration=0.3, fadeout_duration=0.2, growth_curve='linear', fadeout_curve='linear', color='#FFFFFF44', fadeout_on_exclusive_access=True)¶

Enables the touch ripple effect for a widget until the returned coroutine is cancelled.

Parameters:

  • relative_coordinates – Must be set to True if the widget uses relative coordinates (e.g. RelativeLayout, Scatter).

  • clip_to_bounds – Whether ripples are clipped to the widget’s bounding box. You may want to set this to False if the widget already clips its contents on its own.

  • touch_filter (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent], bool]) – Any touch whose on_touch_down event does not pass this filter is ignored. Defaults to is_colliding_and_not_wheel().

  • allow_multiple – Whether multiple ripples can be shown simultaneously via multi-touch.

  • initial_size – The initial diameter from which ripples grow.

  • final_size (float | None) – The final diameter at which ripples stop growing. If set to None (the default), it is computed as the minimum size required to cover the widget.

  • growth_duration – The animation duration taken to grow ripples.

  • fadeout_duration – The animation duration taken to fade out ripples.

  • growth_curve (str) – The animation curve used to grow ripples.

  • fadeout_curve (str) – The animation curve used to fade out ripples.

  • color (str | Sequence[float]) – The color of the ripples. Can be a hex string or an RGBA sequence.

  • fadeout_on_exclusive_access – If set to True (the default), ripples begin fading out when exclusive access to their corresponding touches is claimed. If set to False, ripples begin fading out only when their corresponding touches end.
