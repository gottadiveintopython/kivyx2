Multi-Tap Gesture Recognition¶

class KXMultiTapGestureRecognizer¶

A mixin class that adds multi-tap gesture recognition capability to widgets.

(Some docstrings in this class are written in Japanese because the corresponding English documentation is already available in enable_multi_tap_gesture_recognition().)

on_multi_tap(n_taps, touches)¶

Fired on each successful multi-tap gesture recognition.

Parameters:

  • n_taps (int) – Equal to len(touches).

  • touches (Sequence) – The MotionEvent instances that triggered the on_multi_tap event, in window coordinates, listed in the order in which they ended (not started).

tap_disabled = False¶

If either disabled or tap_disabled is True, tap gesture recognition is disabled.

tap_max_count = 2¶

例えばこの値が2(既定値)の状態で三連続タップが起きた場合、最初の二回と最後の一回の二組のマルチタップとして認識される。

tap_max_time_interval = 0.3¶

あるタップが起きてから続いて起きたタップまでの経過時間がこの値以下であった場合に限りそれらが一組のマルチタップとして認識され得る。

tap_touch_filter(t)¶

on_touch_down イベントがこの選別をくぐり抜けたタッチのみがタップとして認識され得る。 既定値は is_colliding_and_not_wheel()。

async enable_multi_tap_gesture_recognition(widget, *, touch_filter=<function is_colliding_and_not_wheel>, consume_touch=False, max_time_interval=0.3, max_count=2, on_multi_tap=<built-in function print>)¶

Enables multi-tap gesture recognition for a widget until the returned coroutine is cancelled.

Parameters:

  • touch_filter (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent], bool]) – Any touch whose on_touch_down event does not pass this filter is ignored. Defaults to is_colliding_and_not_wheel().

  • consume_touch (bool) – Whether to consume on_touch_down events that pass the touch_filter.

  • max_time_interval (float) – The maximum time interval allowed between taps to be considered part of the same multi-tap gesture.

  • max_count (int) – The maximum number of taps allowed in a multi-tap gesture.

  • on_multi_tap (Callable[[kivy.uix.widget.Widget, int, Sequence[kivy.input.motionevent.MotionEvent]], Any]) – Called on each successful multi-tap gesture recognition. For its parameters, see KXMultiTapGestureRecognizer.on_multi_tap().
