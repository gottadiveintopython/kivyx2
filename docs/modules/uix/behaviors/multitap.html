Multi-Tap Gesture Recognition¶

async enable_multi_tap_gesture_recognition(widget, *, touch_filter=<function is_colliding_and_not_wheel>, consume_touch=True, max_time_interval=0.3, max_count=2, on_multi_tap=<built-in function print>)¶

Enables multi-tap gesture recognition for a widget until the returned coroutine is cancelled.

Parameters:

  • touch_filter (Callable[[kivy.uix.widget.Widget, kivy.input.motionevent.MotionEvent], bool]) – Any touch whose on_touch_down event does not pass this filter is ignored. Defaults to is_colliding_and_not_wheel().

  • consume_touch – Whether to consume on_touch_down events that pass the touch_filter.

  • max_time_interval – The maximum time interval allowed between taps to be considered part of the same multi-tap gesture.

  • max_count – The maximum number of taps allowed in a multi-tap gesture.

  • on_multi_tap (Callable[[kivy.uix.widget.Widget, int, Sequence[kivy.input.motionevent.MotionEvent]], Any]) – Called on each successful multi-tap gesture recognition. See on_multi_tap() for the callback parameters.

on_multi_tap(widget, n_taps, touches)¶
Parameters:

  • widget – The widget instance that was multi-tapped.

  • n_taps – Equals to len(touches).

  • touches – The MotionEvent instances that triggered the multi-tap, represented in window coordinates, listed in the order in which they ended (not started).
