Switch¶

class KXSwitch¶

Inspired by Flutter’s CupertinoSwitch. Unlike the official Switch, the collide_point method checks for collision against the track area rather than the entire widget.

active¶

Whether the switch is on (True) or off (False).

minimum_height¶

An alias for track_height.

minimum_size¶

An alias for track_size.

minimum_width¶

An alias for track_width.

thumb_active_color¶

The color to use on the thumb when the switch is on.

thumb_disabled_color¶

The color to use on the thumb when the switch is disabled.

thumb_inactive_color¶

The color to use on the thumb when the switch is off.

track_active_color¶

The color to use for the track when the switch is on.

track_disabled_color¶

The color to use for the track when the switch is disabled.

track_height¶

The height of the switch track.

track_inactive_color¶

The color to use for the track when the switch is off.

track_size¶

The size of the switch track. (ReferenceListProperty of track_width and track_height)

track_width¶

The width of the switch track.
